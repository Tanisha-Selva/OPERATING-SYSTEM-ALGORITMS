#  Operating System Algorithm Simulator

This project is a web-based simulator for various Operating System algorithms. It helps students understand and visualize how different CPU scheduling, page replacement, resource allocation, and disk scheduling algorithms work.

The simulator is built using HTML and provides separate pages for each algorithm where users can learn and experiment with the concepts.

##  Algorithms Included

### CPU Scheduling
- FCFS (First Come First Serve)

### Page Replacement
- FIFO (First In First Out)
- LRU (Least Recently Used)
- Optimal Page Replacement

### Resource Allocation
- Banker's Algorithm

### Disk Scheduling
- SCAN
- C-SCAN
- LOOK
- C-LOOK
- SSTF

##  Technologies Used
- HTML
- Basic Web Interface
- Algorithm Simulation Logic

##  Purpose
This project is designed for students studying Operating Systems to help them better understand algorithm behavior through a simple web interface.
